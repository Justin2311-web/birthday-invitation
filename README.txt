生日邀请网站 · 使用说明

1. 解压整个 birthday-invite-website 文件夹。
2. 双击 index.html，即可在电脑或手机浏览器打开。
3. 请保留 assets 文件夹，里面包含你提供的视频和视频封面；不要只单独移动 index.html。
4. 点击“愿意”进入日期选择：
   - 2026 年 11 月 21 日（周六）下午 2:00
   - 2026 年 11 月 22 日（周日）上云顶，出发时间再一起商量
5. 选择节目由谁安排后，即可生成邀请卡；支持保存 PNG。
6. “分享”会优先调用设备原生分享功能。部分浏览器/本地 file 页面不支持原生分享时，会尝试复制邀请文字；请先保存 PNG 再通过聊天软件发送。

建议：若要把网站链接直接发给对方，需要将整个文件夹部署到静态网站托管服务（如 Vercel / Netlify / GitHub Pages），单独发送 index.html 不会包含视频资源。
